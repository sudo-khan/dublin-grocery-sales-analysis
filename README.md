# 🛒 Dublin Grocery Sales Data Analysis

An end-to-end data analysis project exploring Dublin grocery store transaction data to identify top revenue drivers, profit margins, and inventory performance.

## 📌 Project Overview
* **Data Ingestion & Cleaning:** Structured 8 core retail transactions across multiple product categories.
* **Database Management (PostgreSQL):** Designed relational table schema and ran SQL aggregation queries.
* **Exploratory Data Analysis (Python):** Used Pandas, Matplotlib, and Seaborn to analyze item performance.
* **Key Finding:** **Halal Chicken Fillet (1kg)** emerged as the primary profit driver (€300.00 Net Profit).

## 📊 Tech Stack
* **Language:** Python 3.14
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, OpenPyXL
* **Database:** PostgreSQL (`psql`)
* **Environment:** Ubuntu Linux, JupyterLab
